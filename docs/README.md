# Sorokit docs

The Mintlify documentation site for Sorokit. Configuration lives in
`docs.json`; every page is an MDX file under this directory.

To preview locally, from the repository root:

```
pnpm docs:dev
```

Or directly from this directory:

```
npx mint@latest dev
```

`docs/logo/` and `docs/favicon.svg` are Mintlify's generic starter
placeholders and need to be replaced with Sorokit's real logo and
favicon before this site is published.
