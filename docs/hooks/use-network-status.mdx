---
title: "useNetworkStatus"
description: "Fetch RPC node health and the latest ledger, refetched on an interval"
---

Fetches RPC node health and the latest ledger. Refetches every 30 seconds, making it suitable for a network status indicator.

```ts
import { useNetworkStatus } from "@sorokit/hooks";

function useNetworkStatus(options?: UseNetworkStatusOptions): UseQueryResult<NetworkStatus>;
```

## Parameters

| Name              | Type      | Required | Description                                       |
| ----------------- | --------- | -------- | ------------------------------------------------- |
| `options.enabled` | `boolean` | No       | Whether the query should run. Defaults to `true`. |

## Return value

`data` resolves to a `NetworkStatus`:

| Field          | Type                          | Description                                               |
| -------------- | ----------------------------- | --------------------------------------------------------- |
| `health`       | `Api.GetHealthResponse`       | RPC node health, including `status: "healthy"`.           |
| `latestLedger` | `Api.GetLatestLedgerResponse` | The latest ledger's sequence, hash, and protocol version. |

## Example

```tsx
import { useNetworkStatus } from "@sorokit/hooks";

function StatusDot() {
  const { data } = useNetworkStatus();
  return <span>{data?.health.status ?? "unknown"}</span>;
}
```
