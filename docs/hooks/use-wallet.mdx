---
title: "useWallet"
description: "Read wallet connection state and signing functions"
---

Reads the wallet connection state and signing functions for whichever connector was passed to [`SoroformProvider`](/components/soroform-provider)'s `wallet` prop. Exported from `@soroform/wallet-adapter`, not `@soroform/hooks`.

```ts
import { useWallet } from "@soroform/wallet-adapter";

function useWallet(): WalletState;
```

<Warning>Throws if called outside a `SoroformProvider` that was given a `wallet` prop.</Warning>

## Return value

| Field             | Type                                                                 | Description                                                                   |
| ----------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `address`         | `string \| undefined`                                                | The connected account's public key, or `undefined` if not connected.          |
| `network`         | `string \| undefined`                                                | The network passphrase the wallet last reported, if known.                    |
| `isConnected`     | `boolean`                                                            | Whether a wallet is currently connected.                                      |
| `connect`         | `() => Promise<{ address: string }>`                                 | Opens the wallet picker modal and connects the selected wallet.               |
| `disconnect`      | `() => Promise<void>`                                                | Disconnects the current wallet.                                               |
| `signTransaction` | `(xdr, opts?) => Promise<{ signedTxXdr, signerAddress? }>`           | Matches `ClientOptions.signTransaction` from `@stellar/stellar-sdk/contract`. |
| `signAuthEntry`   | `(authEntry, opts?) => Promise<{ signedAuthEntry, signerAddress? }>` | Matches `ClientOptions.signAuthEntry`.                                        |

## Example

```tsx
import { useWallet } from "@soroform/wallet-adapter";

function AccountBadge() {
  const { address, isConnected, connect, disconnect } = useWallet();

  if (!isConnected) {
    return <button onClick={() => connect()}>Connect</button>;
  }
  return <button onClick={() => disconnect()}>{address}</button>;
}
```

<Tip>
  For a ready-made connect/disconnect button, use
  [`ConnectWalletButton`](/components/connect-wallet-button) instead of building your own from
  `useWallet`.
</Tip>

## Wiring into contract.Client directly

`signTransaction` and `signAuthEntry` are shaped to drop straight into `ClientOptions` if you ever need to construct a `contract.Client` yourself instead of going through Soroform's hooks:

```ts
import { Client } from "@stellar/stellar-sdk/contract";

const client = await Client.from({
  contractId,
  rpcUrl,
  networkPassphrase,
  publicKey: wallet.address,
  signTransaction: wallet.signTransaction,
  signAuthEntry: wallet.signAuthEntry,
});
```
