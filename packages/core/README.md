# @sorokit/core

Framework-agnostic core utilities for Sorokit: config types, query key
factories, thin passthroughs to `@stellar/stellar-sdk`'s RPC and Horizon
clients, and error normalization for the Stellar contract error classes.

This package has no React dependency and is safe to use from any
JavaScript environment.

Full documentation: https://docs.sorokit.dev (see the repository root
README for the current status of the docs site).
