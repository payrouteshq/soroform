# @sorokit/hooks

General-purpose React hooks for Sorokit: `useBalance`,
`useTransactionStatus`, `useNetworkStatus`, and `useEffectStream`. All are TanStack Query wrappers or Horizon SSE stream
subscriptions around `@sorokit/core`'s SDK passthroughs.

Full documentation: https://docs.sorokit.dev (see the repository root
README for the current status of the docs site).
